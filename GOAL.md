# GOAL.md

## Program North Star
Build a production-grade **AI-native creative systems training program** where each module teaches a human to operate a reproducible autonomous creative workflow, while GitHub preserves the execution/control plane needed by agents to recover, verify and improve the system without chat memory.

The product is not documentation about AI tools. The product is a human operating model backed by real executable systems and evidence.

## Module 01 — Visual Brand System / Viral Carousels
A student arrives with an idea and leaves with a portable visual system that can reproduce premium branded carousels across tools and runtimes.

Golden path:
`idea → references → Extractor ADN Visual v2 → visual-dna.json → DESIGN.md → template → briefing/assets → generation → QA → SKILL.md → runtime`

Module 01 acceptance remains:
- required images visibly render;
- P00–P17 and T01–T09 actions work;
- JSON → traceable DESIGN.md → SKILL.md taught end-to-end;
- Codex / Claude Code / Higgsfield adapters available;
- exports work;
- responsive/browser/visual QA passes on the exact released artifact.

## Module 02 — Autonomous AI Video Editing
The target is a student-operable system approximately:

`brief + editing references + footage + audio + brand assets → edit system → autonomous edit plan / first cut → story/rhythm/b-roll/captions/motion/audio/color → full-video QA → targeted repair → export master`

Motion.OS and AVE are candidate execution substrates, not the syllabus.

### Active gate
Module 02 training design is **BLOCKED** until:
1. Motion.OS and AVE are forensically recovered from durable state;
2. required capabilities are labeled with evidence;
3. ownership/overlap is mapped;
4. `control-plane/AUTONOMOUS_EDITING_VERTICAL_SLICE_GATE.md` passes on real media;
5. whole-video temporal/semantic/art-direction QA and targeted repair are evidenced sufficiently to support honest student-facing claims.

Use `control-plane/BENCHMARK_GATES.md` as the stage-gate contract.

## Global invariants
- GitHub durable state > conversation memory.
- Claims require evidence; architecture breadth is not product proof.
- Student journey is locked before training UI/artifact architecture.
- One source of truth per prompt/system rule.
- Exact-artifact testing is mandatory for release claims.
- Infrastructure remains hidden unless it improves the student's operating model.
- No new abstraction unless it closes a current P0/P1 or measurably improves creative quality/recoverability.
